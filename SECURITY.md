# Política de Segurança

## Versões suportadas

Correções de segurança são aplicadas à versão mais recente publicada.

## Como reportar uma vulnerabilidade

Se você encontrar uma vulnerabilidade de segurança nesta biblioteca, **não** abra uma _issue_
pública. Em vez disso, reporte-a de forma privada aos mantenedores do projeto (por exemplo, pelo
recurso de _security advisory_ do repositório no GitHub) ou uma DM mesmo.

Inclua, se possível:

- uma descrição do problema e do impacto potencial;
- passos para reproduzir;
- a versão da biblioteca afetada.

Faremos o possível para responder com rapidez e, quando confirmada, publicar uma correção e o
devido reconhecimento.

> Observação: esta SDK consome uma API pública e somente leitura e não armazena credenciais. Ainda
> assim, levamos a sério qualquer questão de segurança na própria biblioteca.
